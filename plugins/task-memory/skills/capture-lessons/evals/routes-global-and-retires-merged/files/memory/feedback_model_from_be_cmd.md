Khi đã có cmd BE, model phía mobile đặt đúng tên field của cmd, không suy từ bản desktop.
**Why:** SHOP-12 đặt theo desktop bị sai 3 field.
**How to apply:** Đọc source cmd BE trước khi viết model.
