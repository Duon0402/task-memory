## Resize/compress images before upload
Seen 1× — SHOP-66 · last 2026-11-03

Resize (max 1280px) and JPEG-compress (quality ~0.7) photos before upload, as the other upload screens do.
**Why:** MR review on SHOP-66 caught photos uploaded at 8 MB each.
**How to apply:** When adding or touching any upload screen, reuse the existing resize/compress step before the request.
